# 回收方使用手册

> 写给实验室里负责处理废旧纽扣电池的同学和老师：怎么把废电池交出去、怎么查进度、积分怎么到手、怎么花掉。

## 一、你是谁，能做什么

**你是「回收方」**：把实验室用剩、报废的纽扣电池交给平台的人。平台按实际重量和品类给你积分。

你能做的事：

1. **预约上门回收**——批量大、或者有鼓包漏液的电池时用。
2. **自己寄出**——量小（不超过 2kg）时用，自己打包交给快递。
3. **查回收单进度**——每一单走到哪一步、实际称了多少、发了多少积分。
4. **每天答一道环保题**——答对拿积分，每天一次。
5. **用积分兑换商品**——积分够就能在兑换专区换东西。
6. **管理地址、改昵称头像、看回收指南**。

### ⚠️ 一个人可以同时是「回收方」和「采购方」

同一个微信号只有**一个账号**，但可以在两种身份下使用：回收方（交电池、赚积分）和采购方（买电池、买耗材）。**积分、地址、资料是同一份**，只有界面不一样——两边的底部标签栏就不同：

| 你登录时选的 | 底部标签栏 | 首页 |
|---|---|---|
| 实验室/研究所用户（回收方） | 回收 · 订单 · 我的 | 实验室回收中心 |
| 采购端用户（采购方） | 商城 · 购物车 · 我的 | 采购中心 |

**身份不能一键切换，只能退出后重新登录并选另一个身份：**

1. 底部「我的」→ 页面最下面「退出登录」。
2. 弹窗「确定要退出登录吗？」→ 确定。
3. 回到登录页，点另一张身份卡片（实验室/研究所用户 或 采购端用户）。
4. 点「微信一键登录」——老用户直接进首页，不用再填头像昵称。

⚠️ **退出登录会清空这台手机上的本地数据，包括购物车。** 退出前如果购物车里还有东西，回来就是空的。积分、订单、地址在服务器上，不会丢。

（采购方那套界面怎么用，见《采购方使用手册》，本手册不重复。）

## 二、快速上手（3 分钟走通主流程）

1. **选身份登录**：打开小程序 → 点左边绿色卡片「实验室/研究所用户」→ 弹窗「欢迎登录」→ 点「微信一键登录」。第一次用会进「完善信息」页：点头像选一张图、填昵称 → 点「进入纽启新生」。新用户注册送 **100 积分**。
2. **看首页**：最上面绿色卡片右侧「当前积分」就是你的余额，点整张卡片（或右下「积分兑换 >」）进积分商城。首页往下依次是滚动公告、「累计回收重量」和「累计碳减排量」两张数据卡（点碳减排那张会弹「环保贡献证书」），以及「知识中心」里的「每日一识」。
3. **选回收方式**：首页「回收服务」区有两张卡片——左边「寄送处理 / 小批量电池寄送」，右边「上门回收 / 大批量专业回收」。**超过 2kg 只能选「上门回收」**。
4. **填单**：联系人、联系电话、地址、预估重量（kg）。上门还要选「电池类型」。
5. **提交**：寄送页点底部「提交订单」；上门页点底部「立即预约」，弹「确认下单」后点确定。
6. **看进度**：底部标签栏第二个「订单」→ 在「全部 / 进行中 / 已完成」里找你的单 → 点「查看详情」。
7. **等结算**：平台收走电池后现场称重、按实际重量发积分。订单变成「已完成」后，详情页「结算信息」里能看到「实际重量」和「获得积分」。
8. **花积分**：「我的」→「积分中心」→ 在「兑换专区」点「兑换」。

## 三、详细功能说明

### 3.1 我要交废电池（预约上门）

**什么时候用**：预估重量超过 2kg；品类多；有鼓包、漏液等危险电池；希望有人上门取。

**操作步骤**

1. 首页「回收服务」→ 点右边那张「上门回收 / 大批量专业回收」卡片。
2. 填「联系人」：可以手输，也可以点输入框右侧的「选择」，从地址簿里挑一个联系人（会自动带回姓名、电话、地址）。
3. 填「联系电话」：手机号，数字键盘。
4. 填「上门地址」：多行输入，写清楼、实验室房间号。
5. 选「电池类型」：点下拉框，可选「纽扣锂电池」「普通干电池」「其他废旧电池」。
6. 填「预估重量 (kg)」：可以带小数（如 0.35）。填完下方「费用明细」会自动重算。
7. 点底部「立即预约」→ 弹「确认下单：预计总费用 X 元，是否确认？」→ 确定 → 提示「预约成功」。

**字段怎么填**

| 字段 | 填什么 | 注意 |
|---|---|---|
| 联系人 | 交电池的人 | 不是收件人，别填快递员 |
| 联系电话 | 手机号 | 回收员靠这个联系你，填能接通的 |
| 上门地址 | 学校/院系/楼栋/房间号 | 越具体越好，避免只写「某大学」 |
| 电池类型 | 下拉三选一 | 只影响填报信息，具体品类由平台现场判定 |
| 预估重量 | 公斤，可小数 | 只用于安排回收，**发积分按现场称的实际重量** |

**⚠️ 注意事项**

- **预约时间页面没有入口。** 系统默认按次日 09:00 生成预约时间，会显示在订单里；要改时间请打客服电话 400-123-4567 报订单号，页面上的输入框都不能改它。
- **没有支付步骤，不会扣钱。** 页面「费用明细」里显示「上门服务费」（¥20）、「处理费」（¥5/kg，按你填的预估重量算），下面合计成「预估总费用」，提交后弹窗还会报一次金额；但回收单提交后流程里**没有付款环节**，不会从微信扣款。对费用有疑问，先联系客服再提交。
- **别虚报重量。** 结算按平台现场称的实际重量算，虚报不会多拿积分，反而可能被驳回。
- **鼓包、漏液的电池单独密封**，操作时戴手套，并在交接时主动告诉回收员。
- 提交后想取消：小程序里**没有取消按钮**，请打客服电话处理。

### 3.2 我要交废电池（送到站点 / 寄送处理）

**什么时候用**：量小，预估重量**不超过 2kg**，自己能打包交给快递。

小程序里这个入口叫「寄送处理」，实际流程是**自己打包、自己交给快递寄出**——页面里没有「回收站点地址/网点列表」，也没有上门取件。

**操作步骤**

1. 首页「回收服务」→ 点左边那张「寄送处理 / 小批量电池寄送」卡片。
2. 「寄件信息」里填：联系人、联系电话、寄件地址（多行）、预估重量 (kg)。重量输入框的灰色提示写着「最大不超过 2kg」。
3. 「物流与凭证」里选「物流方式」：下拉可选「京东快递」「顺丰速运」「韵达快递」「圆通速递」。
4. 「处理凭证 (可选)」：点「+ 上传照片」，可拍照或从相册选 **1 张**（打包好的照片、称重照片都行），不传也能提交。
5. 点底部「提交订单」→ 提示「下单成功」→ 自动返回上一页。
6. 系统会自动生成一串 **SF 开头**的快递单号，提交时不需要你手填。寄出后可在「订单」列表和详情里看到这个单号。

**⚠️ 注意事项**

- **重量超过 2kg 会被挡住。** 预估重量一填超过 2，输入框下面立刻出现红字「⚠️ 重量超过 2kg，请选择上门回收服务」；这时点「提交订单」会弹「重量超过限制」，提交不出去。请改用「上门回收」。
- **提交不等于寄出。** 平台不会上门取件，你需要真的把包裹交给快递公司寄出。
- 四个必填项（联系人、联系电话、寄件地址、预估重量）缺任何一个，点提交会提示「请填写完整信息」。
- 打包要求见本手册 3.8：正负极贴绝缘胶带、按型号分开装、鼓包漏液单独密封。
- 提交后同样**没有取消按钮**，需要取消请联系客服。

### 3.3 怎么看我的回收单到哪一步了

**入口**：底部标签栏第二个「订单」。

**列表页怎么读**

- 顶部三个标签：「全部」「进行中」「已完成」。点哪个就只看哪一类。
- 每张卡片包含：订单号、状态（右上角）、回收类型（「寄送处理」或「上门回收」）、预估重量、获得积分（结算后才有）、快递单号（寄送单）或预约时间（上门单）、下单时间。
- 卡片右下有两个按钮：「查看详情」，以及「验收」。

**「验收」按钮是什么**：它不会改变订单，只会弹出一段说明——「关于验收与结算：回收物送达后由平台工作人员现场称重，并按实际重量发放积分。结算完成后积分自动到账，可在「我的积分」中查看明细。」点「知道了」关闭。

**详情页有五个板块**

| 板块 | 内容 |
|---|---|
| 顶部状态卡 | 状态 + 一句话说明（等待系统分配回收员 / 回收员正在处理中 / 订单已完成，积分已发放 / 订单已取消） |
| 订单信息 | 订单编号、下单时间、回收类型 |
| 物品信息 | 预估重量；寄送单看「快递单号」，上门单看「预约时间」 |
| 联系信息 | 联系人、联系电话、取货地址 |
| 结算信息 | 只有「已完成」才出现：实际重量、获得积分 |

**⚠️ 三个容易困惑的地方**

- **列表里的状态只有四档**：待处理、处理中、已完成、已取消。它比后台的细分状态粗：「待处理」同时包含「待审核」和「待回收」两个阶段，「处理中」对应「待结算」。想知道更细的进展，以详情页的状态说明为准，或打客服电话报订单号。
- **审核被驳回的单，在列表里也归到「已取消」这一档，而且页面上看不到驳回原因。** 如果你没主动取消却看到「已取消」，请联系客服问原因。
- **回收单没有「取消订单」按钮**。要取消只能联系客服。

### 3.4 每日问答怎么玩

**入口**：首页「知识中心」→ 点「每日环保知识挑战」（右侧写着「Go >」）。卡片上写着「答对即送 10 积分，每天一题」。

**操作步骤**

1. 进入后先「题目加载中...」，然后出现一道题，通常是 4 个选项，标着 A、B、C、D。
2. 点一个选项（选中会高亮）；选错了想改，直接点别的选项即可。
3. 点「确认提交」——提交后**不能改答案**。
4. 结果立刻出来：
   - 答对：绿色提示「🎉 回答正确」，下方给解析，并显示「+N 积分」，同时弹「积分 +N」。
   - 答错：提示「😅 回答错误」，正确选项标绿、你选错的标红，同样给解析，但**不得分也不扣分**。
5. 点「返回主页」回首页。

**⚠️ 注意事项**

- **每天只有一次机会。** 当天答过之后再进这个页面，会直接显示「今日挑战已完成 / 明天再来挑战吧！」，没有题目可答。
- 页面上固定写「答对奖励 10 积分」，**实际分值由题库里这道题设定**（每题 1~100 分，常见 10~20 分）。以提交后弹出的「+N 积分」为准。
- 「暂无题目」说明题库当天没配题，不是你的问题，第二天再看。

### 3.5 积分怎么来的、怎么用

**四个来源**（详细规则见第四节）：

| 来源 | 怎么拿 |
|---|---|
| 注册 | 新用户第一次登录，自动到账 100 积分 |
| 每日问答 | 每天答对一题，按题目分值给 |
| 回收返积分 | 平台称重结算后，按「品类单价 × 实际重量」发放 |
| 采购消费 | 在商城买东西，确认收货后按「1 元 = 1 积分」发放 |

**在哪看余额**：首页最上面绿色卡片右侧「当前积分」；或「我的」→「积分中心」→ 顶部「我的积分」。

**怎么兑换**

1. 「我的」→「积分中心」（也可以点首页卡片的「积分兑换 >」）。
2. 页面顶部是「我的积分」，右侧「明细 >」可以看每笔加减；往下是「兑换专区」，每个商品显示图片、名称、「N 积分」和「已兑 N」。
3. 库存为 0 的商品会盖一层「已售罄」，按钮变成「无货」。
4. 点「兑换」→ 弹「确认兑换：确定消耗 N 积分兑换 X 吗？」→ 确定 → 提示「兑换成功」，余额立刻减少，商品的「已兑」数量 +1。
5. 积分不够时按钮是灰的、点不动；库存为 0 时按钮显示「无货」，同样点不动（真点到时提示「积分不足」「该商品已售罄」）。

**⚠️ 注意事项**

- **兑换没有收货地址选择、也没有支付步骤**：点确定就扣积分，订单直接进入「待发货」，发货到你的默认地址。所以**兑换前一定要先在「地址管理」里设好默认地址**。
- **兑换成功后不能在小程序里取消**（订单已进入待发货，页面上只有「提醒发货」）。换错了请联系客服。
- 积分明细在「明细 >」弹窗里看：每条有说明、时间、`+N` 或 `-N`；没有记录时显示「暂无记录」。
- **积分是账号级的。** 切到采购方身份，余额还是同一个。

### 3.6 地址怎么管理

**入口**：「我的」→「地址管理」。

**列表页**

- 每条显示：姓名、手机号、「默认」标签（设了默认才有）、省市区 + 详细地址。
- 右侧铅笔图标＝编辑这条地址。
- 底部「新增收货地址」。一条都没有时显示「暂无收货地址」。

**新增 / 编辑页**

| 字段 | 说明 |
|---|---|
| 联系人 | 必填 |
| 手机号 | 必填，数字键盘 |
| 地区 | 点一下弹省 / 市 / 区三级选择器 |
| 详细地址 | 必填，街道门牌、楼栋房间 |
| 设为默认地址 | 开关，打开后下单时默认用它 |

- 底部「保存」；编辑已有地址时，底部还有一个「删除」。
- 保存成功提示「保存成功」并自动返回列表。

**⚠️ 注意事项**

- 联系人、手机号、详细地址三项缺任何一个，点保存会提示「请填写完整信息」，不会保存。
- **平时点地址条目本身没有反应**，只有右侧铅笔能进编辑。只有在「寄送 / 上门 / 确认订单」页点「选择」跳进来时，点条目才会把地址带回去——这两种进入方式的区别就在这里。
- 「删除」按钮只在编辑已有地址时出现，新增时没有。

### 3.7 个人资料怎么改

**入口**：「我的」→「完善个人信息」。

1. 点头像区域（下面写着「点击头像修改」）→ 选一张新头像。
2. 「昵称」输入框里改名字，点「保存修改」。
3. 提示「保存成功」，自动返回。

**⚠️ 注意事项**

- 昵称不能为空，否则提示「请输入昵称」。
- **头像保存的是临时图片地址，重启小程序后可能恢复成默认头像**；昵称会稳定保存。对头像有要求的话，建议等平台支持上传后再换。

### 3.8 交投前先看：分类与打包（回收指南）

**入口**：首页「知识中心」→「实验室废旧电池处理指南」（副标题「分类标准 · 绝缘包装 · 泄漏处理」）。

**1. 常见电池分类**

| 类别 | 说明 |
|---|---|
| 纽扣电池 | CR2032、LR44 等，**务必用胶带包裹正负极，防止短路** |
| 柱状干电池 | AA、AAA 碱性电池，保持干燥，避免重压 |
| 软包锂电池 | 易燃易爆，**严禁刺破**，单独存放于防爆袋 |

**2. 安全包装三步**

1. 检查电池外观，有破损或漏液时戴手套操作。
2. 对裸露的金属触点做绝缘处理（贴透明胶带）。
3. 同类电池整齐码放，放进专用回收箱或纸箱。

**3. 紧急情况处理**（电池发热、冒烟、泄漏时）

1. 立即移到空旷通风处。
2. 用干沙或灭火毯覆盖。
3. **切勿用水直接浇灭锂电池火灾。**

## 四、积分规则一览

| 场景 | 积分 | 什么时候到账 |
|---|---|---|
| 新用户注册 | **100 积分** | 注册完成立即到账 |
| 每日问答答对 | 按题目设定，每题 **1~100 分**（题库里通常 10~20 分） | 提交答案、答对后立即到账 |
| 回收返积分 | **品类单价（积分/kg）× 实际重量（kg）** | 平台现场称重、确认结算后到账 |
| 采购消费 | 每消费 **1 元得 1 积分** | 订单完成后（确认收货时）发放 |
| 积分兑换商品 | 扣减对应积分 | 兑换成功立即扣减；兑换失败不扣 |

### 回收品类与单价（每公斤积分）

| 品类 | 每公斤积分 | 说明 |
|---|---|---|
| 锂锰纽扣电池（CR 系列） | 100 | 含锂，危险废物，需单独存放，禁止挤压穿刺 |
| 氧化银纽扣电池（SR 系列） | 180 | 含银，回收价值高，建议按型号分装 |
| 碱性纽扣电池（LR 系列） | 60 | 含锌锰，可与其他混装 |
| 镍氢/镍镉可充纽扣电池 | 150 | 含镍镉，毒性较高，必须单独密封 |
| 混装未分类纽扣电池 | 50 | 需人工二次分拣，单价最低 |
| 鼓包/漏液纽扣电池 | 200 | 危险性高，需佩戴防护用具 |

**算一笔账**：0.5kg 的 CR 系列电池 = 0.5 × 100 = **50 积分**；1kg 的氧化银 = 180 积分；2kg 混装 = 100 积分。同一重量，分类交投和混装交投差好几倍。

**其它两个数字**

- **碳减排**：每回收 1 kg 减排 **0.5 kg CO₂**。首页「累计碳减排量」就是这么累加的，点这张卡片会弹「环保贡献证书」。
- **积分能干什么**：只有一件——在「积分中心」的兑换专区换商品。积分不能提现、不能转给别人。

## 五、常见问题（FAQ）

**1. 我提交了回收单，为什么一直显示「待处理」？**

列表里的「待处理」= 后台的「待审核」+「待回收」两个阶段，也就是「还没轮到上门/寄出」。提交后需要平台人工审核，审核通过后才会安排回收。隔天还是「待处理」，打客服电话 400-123-4567 报订单号问一下。

**2. 电池多重怎么称？没有秤怎么办？**

实验室有电子天平或电子秤最好，按 kg 填（比如 350 克填 0.35）。没有秤时先填一个保守估值——**预估重量只用来安排回收，不参与发积分**，最终按平台现场称的实际重量算。也可以问实验员借用天平，顺便把不同品类分开称、分开装，单价高的品类（氧化银 180、鼓包漏液 200）别混进「混装」里。

**3. 为什么我不能选「寄送处理」？（提示重量超过 2kg）**

预估重量超过 2kg 时，寄送页会立刻显示红字「⚠️ 重量超过 2kg，请选择上门回收服务」，点提交也被拦住（「重量超过限制」）。这是硬规则：**超过 2kg 必须走「上门回收」**。

**4. 积分多久到账？提交完就有吗？**

不是。提交时**不发积分**，要等平台收走电池、现场称重、确认结算，才按实际重量发放。看订单状态变成「已完成」，详情页「结算信息」里有「实际重量」和「获得积分」，同时「积分中心 → 明细」会多一条记录。

**5. 为什么到账积分和我按预估重量算的不一样？**

因为按**实际重量**算，不是预估重量。另外单价按平台核定的品类算，混装只能按「混装未分类纽扣电池」（50 积分/kg）这一档，分类装好的单价高得多。

**6. 为什么我看到了两套界面？怎么切？**

身份是**登录时选的**，选回收方就是「回收/订单/我的」三个标签，选采购方就是「商城/购物车/我的」。要换：底部「我的」→「退出登录」→ 回登录页点另一张身份卡片 →「微信一键登录」。⚠️ 退出会清空本机购物车。

**7. 地址保存了，下单时却找不到？**

按顺序检查：①「我的」→「地址管理」，看列表里到底有没有这条（保存失败的地址不会进列表）；② 确认点过「保存」并且看到了「保存成功」；③ 回到下单页，点地址那一栏的「选择」，在弹出的列表里点这条地址——只有点「选择」进来的列表，点条目才会把地址填回去；④ 下单页地址卡还显示「请选择收货地址」，就说明没带上，回上一步重选。

**8. 预约上门的时间能改吗？**

页面没有选时间的入口，系统默认按次日 09:00 生成，订单里能看到这个时间。要改请打客服电话 400-123-4567 报订单号，页面里的输入框都改不了它。

**9. 我没取消，订单怎么显示「已取消」？**

审核被驳回的回收单，在列表里也归到「已取消」这一档，而驳回原因在当前页面看不到。请打客服电话问原因；被驳回通常是品类不符或重量明显虚报。

**10. 电池寄出去了，在哪看快递单号？**

「订单」列表里，寄送单那一条会显示「快递单号」（系统自动生成的 SF 开头单号）；点「查看详情」，「物品信息」里也有。

## 六、状态说明表

### 回收单状态

| 状态码 | 后台状态 | 你在小程序看到 | 这一步谁在操作 | 你能做什么 |
|---|---|---|---|---|
| 10 | 待审核 | 列表显示「待处理」 | 平台审核你的单 | 等；信息填错了联系客服 |
| 11 | 待回收 | 列表仍显示「待处理」 | 平台安排回收员，或等你寄出 | 保持电话畅通；寄送单把包裹寄出 |
| 12 | 待结算 | 列表显示「进行中」 | 平台现场称重、录入实际重量 | 等积分到账，不用操作 |
| 13 | 已完成 | 「已完成」 | 平台已结算、积分已发放 | 在「结算信息」里核对实际重量和积分 |
| 20 | 已驳回 | 列表同样显示「已取消」 | 平台审核驳回（会写原因） | ⚠️ 页面看不到原因，打 400-123-4567 问 |
| 30 | 已取消 | 「已取消」 | 你或平台取消 | 重新提交一单 |

正常流程只有一条路：**提交 → 待审核 → 待回收 → 待结算 → 已完成**。中间任何一步都可能直接跳到「已驳回」或「已取消」。

### 每一步大概会发生什么

| 阶段 | 系统/平台做什么 | 你要做什么 |
|---|---|---|
| 提交成功 | 生成订单号、记下提交时间 | 寄送单：尽快寄出；上门单：等电话 |
| 审核通过 | 订单进入「待回收」 | 接听回收员电话，确认上门时间 |
| 现场回收 | 称重、录入实际重量 → 「待结算」 | 在场确认重量，有异议当场提 |
| 结算完成 | 按品类单价 × 实际重量发积分，碳减排累加 | 在「积分中心 → 明细」核对 |

### 积分记录里的加减号

| 显示 | 含义 |
|---|---|
| `+100` | 注册奖励到账 |
| `+N` | 问答答对、回收结算、采购奖励到账 |
| `-N` | 积分兑换扣减 |
