# 采购方使用手册

> 写给实验室里负责买纽扣电池和耗材的老师、同学：怎么逛、怎么下单、怎么付款、收货后出问题怎么申请维修。

## 一、你是谁，能做什么

**你是「采购方」**：在平台上给实验室买纽扣电池、耗材的人。

你能做的事：

1. **逛商城、搜商品**——按名称找电池型号。
2. **看商品详情**——价格、库存、已售数量、别人的评价。
3. **加购物车、改数量**——一次买多件，凑单一起结算。
4. **下单结算**——选收货地址、提交订单。
5. **管订单**——付款、取消、催发货、确认收货。
6. **申请维修售后、发表评价**；用积分兑换商品。

### ⚠️ 一个人可以同时是「采购方」和「回收方」

同一个微信号只有**一个账号**，但可以在两种身份下使用。**积分、地址、资料是同一份**，只有界面不一样——两边的底部标签栏不同：

| 你登录时选的 | 底部标签栏 | 首页 |
|---|---|---|
| 采购端用户（采购方） | 商城 · 购物车 · 我的 | 采购中心 |
| 实验室/研究所用户（回收方） | 回收 · 订单 · 我的 | 实验室回收中心 |

**身份不能一键切换，只能退出后重新登录并选另一个身份：**

1. 底部「我的」→ 页面最下面「退出登录」。
2. 弹窗「确定要退出登录吗？」→ 确定。
3. 回登录页，点「采购端用户」那张卡片。
4. 点「微信一键登录」——老用户直接进「采购中心」，不用再填头像昵称。

⚠️ **退出登录会清空这台手机上的本地数据，包括购物车。** 购物车是本机保存的，退出后里面有什么都没了；积分、订单、地址在服务器上，不会丢。

⚠️ 采购方的「我的订单」不在底部标签栏里（底部只有商城、购物车、我的），要从「我的」页面进去。

## 二、快速上手（3 分钟走完一单）

1. **登录**：打开小程序 → 点右侧蓝色卡片「采购端用户」→「微信一键登录」（第一次用要设头像昵称 →「进入纽启新生」）。
2. **找商品**：底部「商城」→ 顶部搜索框输入型号（如「CR2032」）→ 按键盘上的「搜索」。
3. **看详情**：点商品卡片 → 看价格、库存、评价。
4. **选数量**：在「购买数量」那一行点「−」「+」调整件数（默认 1 件，最多到库存数）。
5. **下单**：「立即购买」直接结算；或「加入购物车」后去购物车勾选、点「去结算 (N)」。
6. **确认订单**：确认页面自动带出默认地址 → 核对「商品清单」和「合计」→ 点「提交订单」。
7. **付款**：「我的」→「我的订单」→「待付款」标签 → 对应订单点「去支付」→ 弹「确认支付」→ 支付。
8. **收货**：收到货后核对无误，在「待收货」标签点「确认收货」——订单完成，积分按实付金额到账。

## 三、详细功能说明

### 3.1 逛商城与搜索

**入口**：底部标签栏第一个「商城」（页面标题是「采购中心」）。

**怎么逛**

- 页面是一列商品卡片：左边商品图，右边商品名、价格（`¥` 开头）、「已售 N」。
- 点任意一张卡片进商品详情。
- **下拉可以刷新列表**（重新拉最新库存和价格）。

**怎么搜**

1. 点顶部搜索框（灰色提示「搜索产品」），输入关键词，比如「CR2032」「氧化银」「LR44」。
2. 按手机键盘右下角的「搜索」键。
3. 列表只留下**商品名里包含这个词**的商品。

**⚠️ 注意事项**

- 搜索是在**当前列表里筛**，不是全库搜。搜过一次之后再搜别的词，可能越搜越少；想恢复全部商品，**把搜索框清空、再按一次「搜索」**（或下拉刷新）。
- 搜不到就是名字里没这个词，换个关键词（试型号后四位，如「2032」）。
- 列表里没有「分类筛选」「价格排序」这类入口，只按名称找。

### 3.2 看商品详情、选数量

**页面从上到下**

1. **图片区**：多张图可左右滑动，图多时会自动轮播。
2. **价格行**：`¥` + 价格，右侧「已售 N」。
3. **商品标题**。
4. **购买数量**：一行「−  数字  +」加减号，右侧写「库存 N 件」。
5. **商品评价**：没有评价显示「暂无评价」；有评价会显示最新一条（头像、昵称、星级、日期、内容），标题「商品评价 (N)」右侧「查看全部 >」，点进去是完整评价列表（可点图片放大看）。
6. **商品详情**：商品描述文字。
7. **底部固定栏**：左边「购物车」图标和「客服」按钮，右边两个大按钮「加入购物车」「立即购买」。

**怎么选数量**

- 点「+」加一件，点「−」减一件；**最少 1 件**（1 件时「−」点不动）。
- **最多到库存数**，到顶再点「+」会提示「已达库存上限」。
- 选好的件数会带到「加入购物车」和「立即购买」两处。

**两个购买按钮的区别**

| 按钮 | 结果 |
|---|---|
| 加入购物车 | 提示「已加入 N 件」，商品进购物车，可以继续逛、最后一起结算 |
| 立即购买 | 直接跳到「确认订单」页，只买这一件（数量按你选的） |

**⚠️ 注意事项**

- 商品库存为 0 时点「立即购买」会提示「库存不足」。
- 底部「客服」按钮打开的是微信客服会话，不是电话。
- 详情页**没有「收藏」、没有「规格选择」、没有「优惠券」**，只有数量和两个购买按钮。

### 3.3 加购物车、改数量

**入口**：底部标签栏第二个「购物车」。底部标签栏的购物车图标上有个数字角标，显示的是**购物车里商品的总件数**（不是几种商品）。

**页面怎么用**

- 每行：左边的圆圈是勾选框（勾上才参与结算）、商品图、商品名、价格、「− 数字 +」数量、最右边「×」删除。
- 底部：「全选」勾选框、右侧「合计: ¥X」、「去结算 (N)」按钮（N 是已勾选的总件数）。
- 一件都没有时显示「购物车空空如也」，下面一个「去逛逛」按钮回商城。

**怎么改**

1. 点商品左边的圆圈 → 选中/取消选中；点「全选」→ 全部选中或全部取消。
2. 点「+」「−」改件数（最少 1 件；加到库存上限会提示「库存不足」）。
3. 点「×」→ 弹「确认删除该商品吗？」→ 确定后从购物车移除。
4. 点「去结算 (N)」→ 进「确认订单」页，只结算**勾选了的**商品。

**⚠️ 注意事项**

- 一件都没勾就点「去结算」，会提示「请选择商品」。
- **购物车存在本机，不跟着账号走。** 换手机、清缓存、退出登录之后购物车就空了，别把想买的东西长期放在购物车里。
- 下单成功后，已买的商品会自动从购物车移除。

### 3.4 下单结算（确认订单）

**从哪进来**：购物车点「去结算 (N)」，或商品详情点「立即购买」。

**页面怎么读**

| 区域 | 内容 |
|---|---|
| 最上面地址卡 | 没选地址时显示「+ 请选择收货地址」；有地址时显示姓名、电话、「默认」标签、完整地址，右侧「>」 |
| 商品清单 | 每件商品：图片、名称、`¥` 价格、`x` 件数 |
| 底部固定栏 | 「合计: ¥X」+「提交订单」 |

**操作步骤**

1. 进页面时会**自动带出你的默认地址**（没设默认就取地址簿第一条）。
2. 想换地址：点最上面的地址卡 → 进「选择收货地址」列表 → 点要用的那条 → 自动返回并回填。
3. 核对「商品清单」里的商品和件数——**这个页面不能改数量**，件数不对要返回购物车改。
4. 点「提交订单」→ 提示「下单成功」→ 自动跳到「我的采购订单」，停在「待付款」。
5. 接着点「去支付」完成付款（见 3.5）。

**⚠️ 注意事项**

- 地址卡还显示「请选择收货地址」就点提交，会提示「请选择收货地址」，订单不会生成。
- **确认订单页没有备注框、没有优惠券、没有发票信息**，填不了这些。
- 金额以提交时平台算出的为准；页面上显示的合计只是给你核对。
- 提交成功但一直没付款，订单会在 **30 分钟**后自动关闭（见 3.5 和第六节）。

### 3.5 付款、取消，和订单上的各个按钮

**入口**：底部「我的」→「我的订单」（或「我的」页面顶部「我的订单」卡片，右边「全部 >」可看全部）。

**订单列表怎么读**

- 顶部一排标签，可左右滑：「全部」「待付款」「待发货」「待收货」「待评价」「退款/售后」「已完成」。
- 每张订单卡：订单号、右上角状态、商品图+名称+`¥`价格+`x`件数、底部「共N件商品 合计: ¥X」。
- 卡片右下角是操作按钮，**按钮随状态变化**：

| 订单状态 | 卡片上出现的按钮 |
|---|---|
| 待付款 | 「取消订单」「去支付」 |
| 待发货 | 「提醒发货」 |
| 待收货 | 「确认收货」 |
| 待评价 | 「去评价」「查看详情」 |
| 已完成 | 「申请维修」「查看详情」 |
| 退款/售后 | 显示的是维修单（见 3.6） |

⚠️ **「去评价」按钮可能不出现**：订单完成后平台返回的状态是「已完成」，不是「待评价」，而「去评价」只对「待评价」的订单显示。原因和应对见 3.7。

**付款**

1. 在「待付款」订单上点「去支付」。
2. 弹窗标题「确认支付」、内容「确认支付 ¥X 吗？」→ 点「支付」。
3. 提示「支付成功」，订单状态变成「待发货」。

⚠️ **当前版本的支付是模拟结账**：点确认后订单直接标记为已支付，**不会真的从微信扣钱**，也没有输入密码/指纹的环节。别把它当成真实付款凭证。

**取消**

1. 只有「待付款」的订单能取消：点「取消订单」→ 弹窗标题「取消订单」、内容「确定要取消该订单吗？」→ 确定。
2. 提示「订单已取消」，状态变「已取消」，占用的库存会放回去。
3. 已经付款的订单**没有取消按钮**，只能等收货后走维修/售后。

**提醒发货**

- 「待发货」订单点「提醒发货」，弹的是说明——「发货由平台工作人员操作，通常会在 24 小时内处理。发货后这里会显示快递单号，可用于查询物流。」点「知道了」关闭。
- 它**不会真的给平台发催单**，只是告诉你流程。

**确认收货**

1. 「待收货」订单点「确认收货」→ 弹窗标题「确认收货」、内容「确认已收到商品且无误吗？」→ 确定。
2. 提示「交易完成」，订单变「已完成」，积分按实付金额到账。
3. ⚠️ **确认收货是后面申请维修、发表评价的前提**，也是保修期的起算点。所以收到后先验货：东西不对也基本要先确认收货，才能在「已完成」里点「申请维修」——系统里没有单独的「拒收/退货」流程，收货后的处理方式就是申请维修（见 3.6）。

**看订单详情**

- 点商品区域或「查看详情」进详情页：顶部状态（待付款 / 待发货 / 待收货 / 已完成 / 已取消，下面一句话说明）、收货地址、商品信息与「实付款」、订单编号、下单时间，底部同样有该状态对应的操作按钮。
- ⚠️ 详情页对「已完成」的订单**没有按钮**（不能在那里评价或申请维修），这两个入口只在列表页的卡片上。

### 3.6 申请维修 / 售后

**什么时候用**：收到的东西有问题——坏了、少件、和描述不符。

**前提**：订单必须是「已完成」（或者你已经在「待评价」状态）。所以顺序是：**先确认收货 → 再去「已完成」标签 → 点「申请维修」**。

**操作步骤**

1. 「我的」→「我的订单」→ 切到「已完成」标签。
2. 找到那一单，点「申请维修」。
3. 「故障描述」：必填，写清现象，比如「CR2032 一盒里 20 颗有 5 颗外壳凹陷、电压为 0」。
4. 「上传凭证」：点「+」加图，最多 **3 张**（拍故障件、包装、快递面单都行）；点图上的「×」可删除。
5. 点「提交申请」——**描述为空时按钮是灰的，点不动**。
6. 成功后弹窗告诉你结论：
   - 在保修期内：「申请成功，您的设备在保修期内！」
   - 已过保修期：「申请成功，已过保修期，将会有专人联系您报价。」
7. 之后在「退款/售后」标签里看处理进度。

**保修规则**

- **保修期 12 个月，从「确认收货」那天开始算**（不是下单日）。没有收货时间的，按下单时间算。
- 保修期内免费处理；过保会有专人联系你报价，你同意后再修。

**「退款/售后」标签里能看到什么**

- 每条是**维修单**，不是商品订单：维修单号、状态、故障描述、申请时间、以及一行结论——「保修期内 (免费)」或「保修期外 (收费)」。
- 状态有四种：`⏳ 等待商家审核`、`🔧 商家已接单，维修中`、`✅ 维修服务已完成`、`❌ 申请被拒绝`。

**⚠️ 注意事项**

- 维修单提交后**页面上没有「撤销售后申请」按钮**，申请前想清楚。
- 维修单目前只能看状态，**这个列表里没有联系客服的入口**；有补充信息请从「我的」→「联系客服」走微信客服，报维修单号。
- 维修单是按**订单**申请的，不细分到某一颗电池；一单里多件商品都有问题，写在同一张维修单里就行。

### 3.7 发表评价

**什么时候能评**：订单状态是「待评价」时（也就是已完成、还没评过）。

⚠️ **先看这一条**：当前版本订单确认收货后会直接显示「已完成」，而「去评价」按钮只在「待评价」状态下才出现。如果你在「待评价」标签里只看到「查看详情」、没有「去评价」，是入口还没开放，不是你的问题——评价不影响收货、积分和保修。

**操作步骤**（按钮出现时）

1. 「我的」→「我的订单」→ 切到「待评价」标签。
2. 订单卡上点「去评价」（旁边可能有个小气泡写着「评价得 5 积分」，点气泡右上的「×」可以关掉它）。
3. 评价页里**每个商品一张卡**，逐个评：
   - 「商品评分」：点星星，1~5 星；右侧文字跟着变（非常差 / 差 / 一般 / 好 / 非常好）。**默认就是 5 星**，不打分直接提交就是五星好评。
   - 评价内容：文本框里写使用心得（最多 200 字），可以不写。
   - 「晒图」：点相机图标加图，最多 **3 张**；点图上的「×」删除。
4. 全部评完，点底部「发布评价」→ 提示「评价成功」→ 自动返回上一页。

**⚠️ 注意事项**

- **一张订单只能评一次**，提交后不能再改、不能补评。
- 同一单里多个商品要一次提交完（页面是一次性提交整单）。
- 图片用的是手机本地图片，重进小程序后可能显示不出来。
- **评价目前不发放积分。** 订单卡上那个「评价得 5 积分」的气泡是页面提示，实际不会加积分；积分以「积分中心 → 明细」为准。

### 3.8 查看积分、兑换商品

**积分从哪来**（采购方最直接的一条）：**买东西，确认收货后按「1 元 = 1 积分」发放**。回收方的回收返积分、每日问答积分也是同一个余额。

**在哪看**：底部「我的」→「积分中心」→ 顶部「我的积分」；右侧「明细 >」看每笔加减和时间。

**怎么兑换**

1. 「积分中心」往下是「兑换专区」，每件商品显示图片、名称、「N 积分」、「已兑 N」。
2. 库存为 0 的盖着「已售罄」，按钮是「无货」。
3. 点「兑换」→ 弹「确认兑换：确定消耗 N 积分兑换 X 吗？」→ 确定 → 提示「兑换成功」，积分立刻扣掉。
4. 兑换成功后订单**直接进入「待发货」**，在「我的订单」里能看到，和普通采购订单混在一起。

**⚠️ 注意事项**

- **兑换没有选地址这一步**，直接发你的**默认地址**。兑换前先去「我的」→「地址管理」把默认地址设对。
- 积分不够时按钮置灰，点不动；售罄提示「该商品已售罄」。
- 兑换成功后**不能在小程序里取消**，该订单也没有「取消订单」按钮。换错了请联系客服。
- 兑换订单没有支付步骤，扣的是积分，不扣钱。

### 3.9 收货地址怎么管理

**入口**：「我的」→「地址管理」。

- 列表每条显示：姓名、手机号、「默认」标签、省市区+详细地址；右侧铅笔图标可编辑；底部「新增收货地址」。
- 新增/编辑页要填：联系人、手机号、地区（省市区选择器）、详细地址、是否设为默认地址；底部「保存」，编辑时还有「删除」。
- 三项必填（联系人、手机号、详细地址）缺一项会提示「请填写完整信息」。

**字段细节、容易踩的坑（例如「地址保存了但下单时找不到」）见《回收方使用手册》3.6 与 FAQ 第 7 条**，两边是同一套地址簿。

### 3.10 个人资料怎么改

「我的」→「完善个人信息」→ 点头像换头像、改昵称 →「保存修改」→「保存成功」。昵称不能为空。

⚠️ 头像保存的是临时图片地址，重启小程序可能恢复默认头像；昵称会稳定保存。

## 四、积分规则一览

| 场景 | 积分 | 什么时候到账 |
|---|---|---|
| 新用户注册 | **100 积分** | 首次登录后立即到账 |
| 采购消费 | 每消费 **1 元得 1 积分** | 订单完成后（你点「确认收货」时）发放 |
| 回收返积分 | **品类单价（积分/kg）× 实际重量（kg）** | 平台称重结算后（回收方身份下） |
| 每日问答答对 | 按题目设定，每题 **1~100 分**（通常 10~20 分） | 答对后立即（回收方身份下） |
| 积分兑换商品 | 扣减对应积分 | 兑换成功立即扣；兑换失败不扣 |
| 发表评价 | **目前不发放积分** | — |

### 回收品类单价（回收方口径，采购方仅作参考）

| 品类 | 每公斤积分 |
|---|---|
| 锂锰纽扣电池（CR 系列） | 100 |
| 氧化银纽扣电池（SR 系列） | 180 |
| 碱性纽扣电池（LR 系列） | 60 |
| 镍氢/镍镉可充纽扣电池 | 150 |
| 混装未分类纽扣电池 | 50 |
| 鼓包/漏液纽扣电池 | 200 |

**算一笔账**：买 200 元的电池，确认收货后得 200 积分；这 200 积分在兑换专区能换对应标价的商品。回收 1kg 氧化银电池得 180 积分。所以对实验室来说，「买了用、用完回收」两头都能攒积分。

**积分能干什么**：只有一件——在「积分中心」的兑换专区换商品。不能提现，不能转给别的账号。

## 五、常见问题（FAQ）

**1. 下单后没付款，订单会怎样？**

**30 分钟内**不付款，系统会自动关闭该订单，列表里显示为「已取消」，占用的库存会放回去。想买就重新下一单。

**2. 点「去支付」是真的扣钱吗？**

不是。当前版本是**模拟结账**：弹窗点「支付」后订单直接变成「待发货」，不会从微信扣款，也没有支付密码环节。真正付款要等平台接入微信支付。

**3. 收到货发现有问题（坏的、少件、和描述不符）怎么办？**

先别急着评价，按这个顺序：① 在「待收货」点「确认收货」（不确认收货，系统里没有「申请维修」入口）；② 到「已完成」标签找到这单；③ 点「申请维修」，写清故障、最多传 3 张图，提交。保修期内免费（**12 个月，从确认收货算**），过保会有专人联系你报价。

**4. 点了「提醒发货」，为什么没反应？**

它是说明弹窗，不是真的催单，内容写着「发货由平台工作人员操作，通常会在 24 小时内处理」。超过这个时间还没发，从「我的」→「联系客服」找人工。

**5. 评价真的能得 5 积分吗？**

订单卡上那个小气泡确实写着「评价得 5 积分」，但**当前版本评价不发放积分**。你的积分以「积分中心 → 明细」里的记录为准，明细里没有的就不会到账。

**6. 为什么我看到了两套界面？怎么切？**

身份是**登录时选的**：采购方是「商城/购物车/我的」，回收方是「回收/订单/我的」。要换：「我的」→「退出登录」→ 回登录页选另一张身份卡片 →「微信一键登录」。⚠️ 退出会清空本机购物车。

**7. 地址保存了，下单时却找不到？**

①「我的」→「地址管理」看列表里到底有没有这条；② 确认点过「保存」并看到「保存成功」；③ 回下单页点最上面地址那一栏，在弹出的「选择收货地址」里点这条——只有从这里点条目才会回填；④ 地址卡还显示「请选择收货地址」就说明没带上，退回重选。

**8. 购物车怎么突然空了？**

购物车存在**这台手机本地**。退出登录（会清空本地数据）、清小程序缓存、换设备，都会让购物车变空。已经提交的订单不受影响，在「我的订单」里能查。

**9. 加购提示「已加入 N 件」，为什么购物车角标显示的不是 N？**

角标显示的是**购物车里所有商品的总件数**（各行件数相加），不是商品种类数。加购同一商品会累加件数，超过 99 显示「99+」。

**10. 兑换的商品什么时候到？去哪看？**

兑换成功后订单**直接是「待发货」**，在「我的」→「我的订单」→「待发货」里；后续发货、收货、确认收货流程和普通采购订单完全一样。

**11. 想买的数量超过库存，怎么办？**

数量到库存上限就加不上去了（提示「已达库存上限」）。购物车里加到上限会提示「库存不足」。先按现有库存下单，或者等补货。

## 六、状态说明表

### 采购单状态

| 状态码 | 后台状态 | 你在小程序看到 | 这一步谁在操作 | 你能做什么 |
|---|---|---|---|---|
| 40 | 待支付 | 「待付款」 | 你（付款） | 点「去支付」；不想买了点「取消订单」；30 分钟不付自动关闭 |
| 41 | 待发货 | 「待发货」 | 平台打包发货 | 点「提醒发货」看说明；等快递 |
| 42 | 待收货 | 「待收货」 | 快递送货，你签收 | 收到并核对无误后点「确认收货」 |
| 43 | 已完成 | 「已完成」（「待评价」标签里也能看到） | 平台已结算，积分已发放 | 「申请维修」「查看详情」；评价入口见 3.7 |
| 50 | 已关闭 | 列表显示「已取消」 | 系统（超时未付自动关闭） | 重新下单 |
| 30 | 已取消 | 「已取消」 | 你（付款前取消） | 重新下单 |

正常流程：**提交订单 → 待付款 → 待发货 → 待收货 → 已完成**。付款前可取消（30），超时不付会自动关闭（50）。

### 维修单状态

| 状态码 | 你在小程序看到 | 谁在操作 |
|---|---|---|
| 1 | `⏳ 等待商家审核` | 平台审核你的申请 |
| 2 | `🔧 商家已接单，维修中` | 平台处理中 |
| 3 | `✅ 维修服务已完成` | 平台已完成，等你确认 |
| 4 | `❌ 申请被拒绝` | 平台驳回，可联系客服问原因 |

维修单旁边还会标一行结论：**「保修期内 (免费)」** 或 **「保修期外 (收费)」**。保修期 12 个月，从确认收货起算。
