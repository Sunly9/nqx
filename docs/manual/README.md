## ⚠️ 一个容易困惑的地方：一个人可以同时是"回收方"和"采购方"

**这不是 bug。** 同一个微信账号既能把废电池交出去，也能采购新电池 —— 两者用的是**同一套积分和同一个账号**。

所以你会看到**两套完全不同的界面**：

| 身份 | 底部标签栏 | 首页长什么样 |
|---|---|---|
| 回收方 | 回收 / 订单 / 我的 | 回收申请入口、今日问答、回收指南 |
| 采购方 | 商城 / 购物车 / 我的 | 商品列表、搜索框、分类 |

### 怎么切换身份

**身份是在「登录时」选的，没有一键切换。** 要换身份：

1. 进「我的」页面
2. 拉到底部，点 **「退出登录」**
3. 回到登录页，重新选择另一个身份卡片
4. 登录后就会进入对应的首页

> **⚠️ 退出登录会清空本地数据**，包括**购物车**里还没结算的商品。
> 所以如果购物车里有东西，先下单或记下来再退出。

**登录页的两张身份卡片**：

| 卡片 | 文案 | 进去之后 |
|---|---|---|
| 实验室 / 研究所 | 电池回收 · 积分奖励 · 环保合规 | 回收端界面 |
| 采购端用户 | 设备采购 · 订单管理 · 售后服务 | 采购端界面 |

## 这个平台是干什么的

高校实验室每年会产生大量**废旧纽扣电池**。它们含汞、镉、锂等重金属，属于**危险废物**，不能随手丢进垃圾桶。

「纽启新生」做两件事：

1. **回收** —— 实验室把废电池交出来（预约上门 或 送到站点），按重量和品类换积分，平台记录碳减排量
2. **采购** —— 实验室用积分或钱买到合规的纽扣电池与耗材

**积分**是整个平台的纽带：交电池赚积分，买耗材花积分。

## 三分钟了解关键数字

| 项 | 数值 |
|---|---|
| 新用户注册奖励 | **100 积分** |
| 回收返积分 | **按品类单价 × 重量**，单价 50~200 积分/公斤 |
| 采购返积分 | 每消费 **1 元 = 1 积分**（订单完成后发放） |
| 碳减排 | 每回收 **1 公斤** ≈ 减排 **0.5 公斤** CO₂ |
| 维修保修期 | **12 个月**（从确认收货起算） |
| 客服电话 | 400-000-0000 |

## 手册之间怎么配合

```
回收方手册  ←─ 都讲"怎么用小程序"，只是身份不同
采购方手册  ←─
     │
     │  他们提交的单据，由管理员处理
     ▼
管理员手册  ←─ 审核回收单、发货、调积分
     │
     │  系统由运维部署与维护
     ▼
部署运维手册 ←─ 装环境、起服务、备份、排查
```

**一个典型的完整闭环**：

1. 实验室（回收方）提交回收申请
2. 管理员审核通过 → 上门回收 → 录入实际重量 → 结算积分
3. 实验室（采购方）用积分或钱下单买新电池
4. 管理员发货
5. 实验室确认收货 → 可以评价、可以申请维修
